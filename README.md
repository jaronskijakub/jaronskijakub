# Jaron

Angular enjoyer. Backend curious.

Six years of Angular, from micro-frontends with Module Federation to RxJS, NgRx and now Signals. Lately I've been poking at the backend in C#/.NET and Python, mostly to find out what happens after my HTTP calls leave the browser. I build with Claude Code every day.

## Things I've shipped

**[jestzlecenie.pl](https://jestzlecenie.pl)** · *private repo*
A local marketplace where neighbors hire neighbors for jobs nobody wants to do alone: moving furniture, fixing things, gardening. I built the Angular frontend solo, from first commit to real users. It's still running.

**[retrofantasy.football](https://retrofantasy.football)** · *private repo*
A fantasy football game where you draft a squad from a historical World Cup knockout round and survive against progressively older eras. Scoring runs server-side so players can't see results early. I built it with React and FastAPI, mostly through Claude Code.

## Open source

**[fatsecret-mcp](https://github.com/jaronskijakub/fatsecret-mcp)**
An MCP server that lets me log food to my FatSecret diary by talking to Claude on my phone. I send a photo of my plate, Claude shows a draft with calories and macros, and nothing hits the diary until I say yes. Python, self-hosted, on [PyPI](https://pypi.org/project/fatsecret-mcp/) and in the official MCP registry.

**[hevy-mcp](https://github.com/jaronskijakub/hevy-mcp)**
I log every gym session in Hevy. Now I just ask Claude "is my bench still going up?" and get real numbers back, not a guess. The server crunches my whole training history in C#, so Claude only has to explain the results.
